# 网页翻译助手 - Chrome 扩展

一个功能强大的 Chrome 浏览器翻译插件，支持中英互译、自动检测文本、自定义翻译样式。

## 功能特性

- 🌐 **自动翻译**：自动检测网页文本并进行翻译
- 🔄 **中英互译**：支持中文与英文的双向翻译
- 🎨 **自定义样式**：可自定义翻译文本的颜色、背景、透明度等样式
- 🔧 **灵活配置**：支持设置目标语言、翻译位置、是否显示原文等
- 🚀 **实时预览**：在设置面板中实时预览翻译效果

## 安装方式

1. 下载或克隆此仓库
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目中的 `src` 文件夹

## 使用方法

1. 安装扩展后，点击浏览器工具栏中的扩展图标
2. 在弹出的面板中开启翻译功能
3. 访问任意网页，扩展会自动翻译页面文本
4. 可在面板中调整翻译样式、目标语言等设置

## 项目结构

```
src/
├── background/     # 后台服务脚本
├── common/         # 公共工具模块
│   ├── storage.js      # 存储管理
│   ├── translator.js   # 翻译核心
│   └── utils.js        # 工具函数
├── content/        # 内容脚本（注入到页面）
├── icons/          # 扩展图标
├── options/        # 选项页面
├── popup/          # 弹出面板
└── manifest.json   # 扩展配置文件
```

## 开发说明

本项目采用原生 JavaScript 开发，无需额外的构建工具。直接修改 `src` 目录下的文件即可。

### 主要模块说明

- **content.js**：核心翻译逻辑，负责页面文本的检测和翻译
- **popup.js**：弹出面板的交互逻辑，处理用户设置
- **background.js**：后台服务，处理扩展生命周期和消息通信
- **translator.js**：翻译核心模块，封装翻译API调用
